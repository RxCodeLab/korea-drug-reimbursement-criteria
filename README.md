# 약제 급여기준 변경 이력 검색

약제명이나 성분명으로 급여기준의 과거 변경 내용을 찾아보는 검색 서비스입니다.

보건복지부 고시 「요양급여의 적용기준 및 방법에 관한 세부사항(약제)」를 대상으로 하며, 법제처 Open API에서 수집한 자료를 이용합니다.

[검색 서비스 열기](https://rxcodelab.github.io/korea-drug-reimbursement-criteria/)

> 검색 결과는 편의를 위해 원문을 가공한 참고자료이므로, 실제 급여 적용이나 청구 판단이 필요한 경우 최신 고시 원문을 확인해야 합니다.

## 검색할 수 있는 내용

- 한글·영문 약제명과 성분명
- 급여기준의 신설·변경·삭제 이력
- 각 기준의 시행일과 고시번호
- 시행 시점별 급여기준 본문

## 검색 방법

검색창에 약제명이나 성분명을 입력합니다.

```text
다파글리플로진
dapagliflozin
다파글리플로진 dapagliflozin
```

검색어를 여러 개 입력하면 하나라도 포함된 결과를 표시합니다. 같은 급여기준의 변경 내용은 시행일 순으로 묶어서 보여줍니다.

## 자료 갱신

매일 새 고시가 있는지 확인하고, 검증을 통과한 자료만 검색 결과에 반영합니다. 갱신 과정에서 문제가 발견되면 마지막으로 정상 확인된 자료를 유지합니다.
